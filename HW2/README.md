# ПОС - преподавательская оценка студентов

Консольное приложение на C# и .NET 10: студенты, критерии, оценки, взвешенные итоги и экспорт CSV.

## Запуск

Нужен .NET 10 SDK. Команды выполняются из `SD/HW2`. В Rider откройте `Pos.sln` и запускайте `Pos.Console`.

```bash
dotnet build Pos.sln -m:1
dotnet run --project Pos.Console
```

Демо со студентами, оценками, исправлением, отменой и экспортом:

```bash
dotnet run --project Pos.Console -- --demo
```

Демо работает в памяти и не меняет пользовательскую ведомость. Выход из меню - `0`. Дробные числа принимаются с точкой или запятой.

## Правила

- Id студентов и критериев положительны и уникальны в своих списках. Имена и названия непустые.
- Максимум и вес критерия больше нуля. Балл находится в диапазоне `[0, MaxScore]`.
- Оценка относится к существующему студенту и критерию рубрикатора.
- На пару `(StudentId, CriterionId)` приходится одна оценка. Для изменения есть отдельный метод.
- Неверное исправление сохраняет старую оценку. Отмена удаляет её, а не заменяет нулём.

```text
Итог = 10 * сумма(score / maxScore * weight) / сумма(weight)
```

Окончательный итог доступен только при всех оценках. Предварительный учитывает пропуски как нулевой вклад и включает веса всех критериев. Пустой рубрикатор не даёт итога. Добавление критерия делает оценивание неполным.

Итог пересчитывается при запросе. Вывод округляется до трёх знаков. Пример: `8/10` с весом `1` и `15/20` с весом `3` дают `7,625`. Общая ведомость показывает также число полностью оценённых студентов и средний балл среди рассчитанных итогов выбранного режима.

## DDD

| Понятие | Реализация |
| --- | --- |
| Язык предметной области | Student - студент, Criterion - критерий, Rubric - рубрикатор, Evaluation - оценка, Gradebook - ведомость |
| Entity | Student и Criterion различаются по Id. Одинаковые имена не делают студентов одной сущностью |
| Value Object | Weight - неизменяемый вес без Id; два экземпляра с одинаковым значением равны |
| Агрегат | Gradebook управляет студентами, рубрикатором и оценками одного курса, проверяет их связи |
| Инварианты | Конструкторы проверяют значения, Gradebook - уникальность, принадлежность и допустимость операций |
| Repository | IGradebookRepository - интерфейс загрузки и сохранения ведомости |
| Domain Service | FinalScoreCalculator рассчитывает итог по актуальным критериям и оценкам |

Один агрегат выбран для проверки связанных правил перед сохранением ведомости. Коллекции доступны снаружи только как снимки для чтения.

## Архитектура и паттерны

Облегчённая Clean Architecture:

| Проект | Назначение |
| --- | --- |
| Pos.Domain | Модель, проверки, расчёт итогов |
| Pos.Application | Сценарии, фасад, интерфейсы хранения и экспорта |
| Pos.Infrastructure | JSON-хранилище, хранилище в памяти, CSV-экспорт |
| Pos.Console | Меню, демо, DI-контейнер и сборка зависимостей |
| Pos.Tests | Модульные и интеграционные тесты |

```text
Application -> Domain
Infrastructure -> Application -> Domain
Console -> Application
Console/CompositionRoot -> Infrastructure, Domain
```

Domain не зависит от консоли и файлов. Сервисы получают зависимости через конструкторы. Собственный SimpleContainer создаёт один экземпляр каждого зарегистрированного типа на запуск; регистрации находятся в CompositionRoot.

| Группа | Паттерн | Применение |
| --- | --- | --- |
| Порождающий | Builder | RubricBuilder собирает рубрикатор; неудачная сборка не заменяет действующий |
| Структурный | Facade | AssessmentFacade даёт консоли общий доступ к оцениванию, отчётам и экспорту |
| Поведенческий | Strategy | StrictScoringStrategy и PreliminaryScoringStrategy определяют выдачу итога при пропусках |

## Хранение

Данные автоматически сохраняются в `data/gradebook.json` относительно рабочей папки. Другой путь:

```bash
dotnet run --project Pos.Console -- --data /tmp/pos/gradebook.json
```

Загрузка проходит через доменные проверки. Повреждённый JSON отклоняется без перезаписи. Сохранение выполняется через временный файл.

CSV экспортируется через меню: UTF-8 с BOM, разделитель - запятая. Отсутствующий итог записывается пустым полем с пояснением. Перед перезаписью файла требуется подтверждение.

Версия рассчитана на один курс и один процесс. Импорт CSV, удаление студентов и изменение существующих критериев не реализованы.
